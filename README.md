# Borozdov Hush

A theme from the Borozdov collection. Two faces — light **Sunbeam**, a sunlit wellness
retreat on warm paper, and dark **Moonrise**, the same retreat under a twilight-violet
night. Rounded bold headlines, huggable pills, one sunbeam yellow card and an orange dot for
what you tick.

![Borozdov Hush in light mode](https://raw.githubusercontent.com/borozdov-obsidian-themes/hush/main/screenshots/light.png)

![Borozdov Hush in dark mode](https://raw.githubusercontent.com/borozdov-obsidian-themes/hush/main/screenshots/dark.png)

## Principles

- **Warm paper, calm type.** A cream page and a warm charcoal text scale, never pure black;
  Cantarell Bold for the title and headings, tracked in tight so they feel confident rather
  than clinical.
- **Three cheerful accents, each in its place.** An orange dot marks a checked task, a
  toggle and the caret; sunbeam yellow is the plain note and the highlighter; mindful blue
  is the main button and links.
- **Huggable shapes.** Every button, tag and the open file is a pill; plain buttons are ink
  pills with a small printed-sticker shadow; cards keep 16px corners, the featured sunbeam
  card 24px.
- **A night sky, not a black one.** Moonrise turns the page twilight violet, and the
  sunbeam takes over the main button and the links.

## Features

- Light and dark modes, following Settings → Appearance → Base color scheme
- Callouts as category cards, white by day and violet by night; the plain note is a
  sunbeam card
- Tags and property values as filter pills that turn ink under the pointer
- Round checkboxes that fill with the orange dot
- Quiet editing: no focus ring around the note, its title or form fields while you type;
  property names read as labels, not boxed fields
- Text colours meet WCAG contrast on both faces
- The phone layout keeps the same colours and shapes
- No `!important`: every rule can be overridden with a CSS snippet

## Installation

**From the community directory:** Settings → Appearance → Themes → Manage, search for
**Borozdov Hush**, then **Install and use**.

**By hand:** download `manifest.json` and `theme.css` from the
[latest release](https://github.com/borozdov-obsidian-themes/hush/releases/latest) into
`<vault>/.obsidian/themes/Borozdov Hush/`, then choose Borozdov Hush under
Settings → Appearance → Themes.

## Font

Cantarell Bold (© 2009–2017 The Cantarell Authors) is embedded in `theme.css` as base64
WOFF2 under the SIL Open Font License 1.1 — see [`fonts/OFL.txt`](fonts/OFL.txt). One
weight, Latin and Cyrillic, for the title and headings only.
